An agent harness · 8 MB · one binary

Run your own Vela.

Vela is a self-hosted agent harness: one static Go binary holding the agent loop, the tool belt, and persistent memory. Point it at any OpenAI-compatible model, give it a chat front end, and it runs — on a server, a laptop, or a credit-card-sized RISC-V board drawing two watts.

> make riscv64 · scp · edit one env file · done
